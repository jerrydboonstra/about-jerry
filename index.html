How I work with agents

Claude Code is my daily tool, with Codex as a second agent. I run them in parallel through Cat Herder, with separate agent sessions reviewing each change before it merges, and I make the product decisions.

TypeScript and Node sit beside Python as my current languages: the CDK stacks for ResumeFactory, the services at ObexMetrics, and a link shortener at Jukin that held 99.999% uptime. From 2018 to 2020 I was a contract architect for Talespin and Girlgaze, often in their offices with their teams. I like owning the whole path from a hard domain problem to a production system, and I explain architecture and tradeoffs to engineers, founders and stakeholders.
